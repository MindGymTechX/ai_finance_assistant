An exit load is a fee for redeeming units before a set period. Many equity funds charge about 1% if redeemed within 1 year; liquid funds have a small graded load for the first few days.

Lock-ins are stricter: ELSS units cannot be redeemed for 3 years from each SIP instalment's date, and some solution-oriented funds lock in for 5 years or until retirement.

Exit loads and taxes together mean frequent switching between funds can quietly cost money.
